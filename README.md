**Neon Bay** is an original open-world crime game set in a fictional sun-soaked
coastal city. You play Rico Vale, a wheelman fresh out of the Marina lockup,
working three jobs across one night for the Bay City crew — while every cop in
Neon Bay tries to stop you.

Explore the city on foot or by car, steal cars, outrun police chases, fight
rival gang members, and finish all three story missions. Features a full HUD
with health, cash, a 5-star wanted level, a live minimap, speed and clock,
plus synthesized sound effects and music — all running offline from static
files, built with three.js.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

Controls: WASD move/drive · SHIFT run · E enter/exit car · F punch ·
mouse click shoot · R reload · M music · C camera · ESC pause.
Progress saves to localStorage.
